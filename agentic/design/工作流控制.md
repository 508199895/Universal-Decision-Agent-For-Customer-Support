# 工作流控制

| 节点 | 输入 | 输出（写入状态） | 工作流 | 使用的工具 / Agent |
|---|---|---|---|---|
| Intake | `ticket.content`<br>`ticket.channel`<br>`ticket.tags`<br>`ticket.owner_name` | `intake.summary`<br>`intake.normalized_issue`<br>`intake.sentiment`<br>`intake.suspected_language` | 1. 读取原始工单<br>2. 生成工单摘要<br>3. 规范化问题描述<br>4. 判断用户情绪<br>5. 识别工单语言<br>6. 写入 `intake` 状态<br>7. 进入 Classifier | 1. LangGraph 状态<br>2–5. Intake Agent<br>6. LangGraph 状态<br>7. LangGraph 边 |
| Classifier | `ticket.content`<br>`ticket.channel`<br>`ticket.tags`<br>`intake.normalized_issue`<br>`intake.sentiment` | `classification.issue_type`<br>`classification.urgency`<br>`classification.complexity`<br>`classification.should_escalate_immediately`<br>`classification.rationale` | 1. 读取工单和 Intake 结果<br>2. 判断问题类型<br>3. 判断紧急程度<br>4. 判断问题复杂度<br>5. 判断是否建议立即升级<br>6. 生成分类理由<br>7. 写入 `classification` 状态<br>8. 进入 Supervisor | 1. LangGraph 状态<br>2–6. Classifier Agent<br>7. LangGraph 状态<br>8. LangGraph 边 |
| Supervisor | `intake.summary`<br>`classification.issue_type`<br>`classification.urgency`<br>`classification.complexity`<br>`resolution.status`（可选）<br>`resolution.confidence`（可选） | `supervisor.next_step`<br>`supervisor.reason` | 1. 读取 Intake、Classification 和 Resolution 状态<br>2. 根据处理状态、置信度、紧急度和复杂度判断下一步<br>3. 生成 `next_step` 和决策原因 `reason`<br>4. 将决策结果写入 `supervisor` 状态<br>5. 条件边 `route_from_supervisor` 读取 `supervisor.next_step` 并路由：`resolver` → Resolver，`escalation` → Escalation，`done` 或其他值 → END | 1. LangGraph 状态<br>2–3. Supervisor Agent<br>4. `supervisor_node`<br>5. LangGraph 条件边 `route_from_supervisor` |
| Resolver | `ticket.content`<br>`ticket.owner_id`<br>`ticket.ticket_id`<br>`intake.normalized_issue`<br>`classification.issue_type` | `resolution.status`<br>`resolution.answer`<br>`resolution.confidence`<br>`resolution.used_kb_articles`<br>`resolution.notes_for_human` | 1. 构造知识库查询内容<br>2. 搜索相关知识库文章<br>3. 计算关键词匹配度和置信度<br>4. 查询客户资料<br>5. 查询客户预订记录<br>6. 搜索客户历史记忆<br>7. 判断问题是否可自动解决<br>8. 不可解决则标记 `needs_escalation`<br>9. 可解决则生成客户答复<br>10. 成功解决后写入长期记忆<br>11. 写入 `resolution` 状态<br>12. 返回 Supervisor | 1. Resolver 节点逻辑<br>2. KB MCP：`kb_search`<br>3. Resolver 节点评分逻辑<br>4. Account MCP：`account_get_user`<br>5. Account MCP：`account_get_user_reservations`<br>6. Memory MCP：`memory_search`<br>7–8. Resolver 节点判定逻辑<br>9. Resolver Agent<br>10. Memory MCP：`memory_write`<br>11. LangGraph 状态<br>12. LangGraph 边 |
| Escalation | `ticket.content`<br>`intake.summary`<br>`intake.sentiment`<br>`classification`<br>`resolution.notes_for_human`（可选） | `escalation.summary_for_human`<br>`escalation.recommended_department`<br>`escalation.proposed_next_steps`<br>`escalation.include_prior_resolution_notes` | 1. 读取工单及已有处理结果<br>2. 生成供人工客服阅读的摘要<br>3. 推荐接手部门<br>4. 生成后续处理步骤<br>5. 判断是否包含 Resolver 备注<br>6. 写入 `escalation` 状态<br>7. 结束工作流 | 1. LangGraph 状态<br>2–5. Escalation Agent<br>6. LangGraph 状态<br>7. LangGraph 边 |
